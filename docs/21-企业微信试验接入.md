# 企业微信试验接入

## 当前已落地

- 自建应用 `access_token` 获取与 Redis 缓存。
- 应用可见范围内的成员详情、部门列表读取。
- 自建应用文本消息投递与连通性检查。
- 后台企业微信 OAuth 登录，以及现有员工账号首次绑定。
- 安全模式回调 URL 校验、SHA-1 签名校验、AES-CBC 解密和幂等入库。
- 客户联系「联系我」创建、客户详情读取的服务端适配器。
- 企业微信成员标识、成员资料和回调正文均加密保存；检索只使用不可逆 HMAC。

## 企业微信管理后台配置

1. 在「应用管理」创建自建应用，应用名称建议为「数智名片」。
2. 应用可见范围至少包含试验成员；成员和部门接口只会返回该范围内的数据。
3. 网页授权可信域名应与管理后台正式 HTTPS 域名一致。
4. OAuth 回调地址配置为：

   `https://<正式域名>/c/admin/wecom/callback`

5. 接收消息服务器 URL 配置为：

   `https://<正式域名>/api/v1/integrations/wecom/callback`

6. 回调使用安全模式，并把后台生成的 Token 与 EncodingAESKey 交给部署密钥管理。
7. 如启用客户联系接口，还需在「客户联系 → 客户 → API」中把该自建应用加入可调用应用。

生产环境不能使用裸 IP 的 HTTP 回调。OAuth 回调和企微服务器回调都应先准备可验证的 HTTPS 域名。

## 部署变量

以下值只能写入服务器密钥文件或密钥管理服务，不得提交到仓库：

```dotenv
WECOM_CORP_ID=
WECOM_AGENT_ID=
WECOM_APP_SECRET=
WECOM_TENANT_ID=
WECOM_COMPANY_ID=
WECOM_OAUTH_REDIRECT_URI=https://<正式域名>/c/admin/wecom/callback
WECOM_CALLBACK_TOKEN=
WECOM_CALLBACK_ENCODING_AES_KEY=
```

`WECOM_TENANT_ID` 和 `WECOM_COMPANY_ID` 是本系统数据库中的企业范围 UUID，不是企微后台编号。

## 首次绑定与日常登录

1. 员工先用现有账号登录后台。
2. 后台请求 `GET /api/v1/auth/wecom/bind-url`，跳转到返回的企微授权地址。
3. 前端把授权回调中的 `code`、`state` 提交到 `POST /api/v1/auth/wecom/bind`。
4. 绑定成功后，员工可在登录页直接使用「企业微信登录」。

OAuth `state` 是 Redis 保存的一次性 64 位随机值，符合企微只允许字母数字且不超过 128 字节的限制；成功或失败消费后不可重放。

## 运维检查接口

- `GET /api/v1/platform/integrations/wecom/status?probe=true`
- `GET /api/v1/platform/integrations/wecom/departments`
- `POST /api/v1/platform/integrations/wecom/test-message`

以上接口仅平台管理员可用，响应不会返回 CorpSecret、Token 或 EncodingAESKey。
