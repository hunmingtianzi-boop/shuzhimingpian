## Why

当前企业模板编辑器虽然具备内容块编辑与发布能力，但创建了独立的后台式视觉语言；公开端在存在已发布模板时还会隐藏原移动端名片的内容目录和固定业务模块。这破坏了已有产品辨识度，也让模板能力看起来像替换名片，而不是扩展名片。

本变更把原移动端名片确立为唯一视觉与信息架构基线：模板编辑只编排扩展内容，不能移除或重绘原有名片外壳。

## What Changes

- 保留公开企业名片的原顶部企业信息、内容目录、定位卡片、固定业务区块与底部操作栏；已发布模板不再替换这些结构。
- 将可选模板块嵌入原名片内容流，继承现有颜色、字型、留白、标题、卡片和交互语言。
- 重构管理端模板编辑器，让桌面编辑态聚焦“目录 + 画布 + 设置”，移动预览完整还原原名片外壳，而不是自建蓝色手机模板。
- 保留全部既有模板功能、员工身份投影、草稿/发布和资源校验契约。

## Capabilities

### New Capabilities

- None.

### Modified Capabilities

- `enterprise-card-template-editor`: 编辑器必须以原移动端名片的导航、目录和视觉 token 为基线，并在桌面编辑态提供清晰的模块目录、画布与设置关系。
- `enterprise-card-template-rendering`: 已发布模板只扩展原名片内容，不得隐藏原内容目录或固定业务模块。

## Impact

- 管理端：模板编辑器结构、实时预览组件与相关样式。
- 公开端：企业模板块插入位置、目录/固定模块的显示条件和模板块视觉样式。
- 测试：新增导航保留、固定模块保留、预览外壳一致性与 390px 浏览器验证。
- 数据/API：无迁移、无端口变化、无模板文档格式变更。
