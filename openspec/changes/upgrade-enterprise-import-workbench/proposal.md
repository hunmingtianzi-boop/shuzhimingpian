## Why

企业工作台当前把文件上传、批次进度、智能候选和 FAQ 列表纵向堆在同一页面，任务 UUID 直接暴露给用户，候选全部展开后难以审核。产品已经确认保留企业资料、核心业务、案例和 FAQ 现有栏目，同时新增独立资料导入工作台，并从各栏目复用同一导入入口。

## What Changes

- 新增企业端“资料导入”导航与独立工作台，保留现有内容栏目和权限。
- 导入批次增加企业内递增编号与可编辑名称；UUID 只用于技术详情。
- 智能候选审核改为分类导航、候选列表和单条编辑/原文证据工作区，支持高置信候选批量接受。
- FAQ 页面不再永久嵌入完整导入面板；企业资料、产品、案例、FAQ 页面右上角统一进入资料导入工作台并携带来源场景。
- 内容发布前显示关联名片数量和明细，二次确认后一键切换已发布版本；保留版本历史和回退入口。
- 第一阶段只提供工作台内状态和待处理角标。

## Non-goals

- 不讨论或重构权限模型，沿用现有权限边界。
- 不改平台“资料辅助建企”流程。
- 不新增解析器、OCR 服务或第二套导入链路。
- 不发送短信、邮件或企业微信通知。
- 不改变运行端口、生产 base path 或公开名片 URL。

## Impact

- Admin Web：导航、路由、资料导入工作台、四个内容页入口、候选审核布局和发布确认交互。
- API/Data：批次编号/名称、重命名接口、候选批量接受、内容影响预览、发布修订与回退记录。
- Public Card：继续按内容 ID 读取当前已发布内容，卡片排版配置保持独立。
